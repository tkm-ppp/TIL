# どういうものか？
- ファビコンとは、Webサイト独自のアイコンのこと

### 例
ブラウザのタブの端、ブックマーク項目の先頭、アドレス欄の端、デスクトップに置くショートカットアイコン

# なぜ使うか？
- Webサイトの認知度向上
- Webサイトのブランディング
- リピーター獲得

## 3.ファイルの生成
- ファビコンに使いたい画像を用途別のサイズとファイル形式で保存
### 必要なファイルの準備
**16x16**
Microsoft Edgeのタブなど
**32x32**
Google Chrome、Safari、Firefoxなどのタブ
**48x48**
Windowsのサイトアイコン
**96x96**
IEやショートカットアイコン
**180x180**
iOSのapple-touch-icon
**192x192**
Androidのホーム画面アイコン、PWAのインストールバナー
**512x512**
高解像度表示やWordPressなど

**推奨サイズ:**
最小限必要なサイズ: 16x16, 32x32, 192x192, 512x512
高解像度対応: 64x64, 96x96, 152x152, 256x256

## 4.HTMLでの設定
```
<link rel="manifest" href="pwa/manifest.json">
<link rel="icon" href="/favicon.ico">
<link rel="icon" type="image/png" sizes="16x16" href="/icon/favicon-16x16.png">
<link rel="icon" type="image/png" sizes="32x32" href="/icon/favicon-32x32.png">
<link rel="icon" type="image/png" sizes="48x48" href="/icon/favicon-48x48.png">
<link rel="icon" type="image/png" sizes="48x48" href="/icon/favicon-96x96.png">
<link rel="icon" type="image/svg+xml" href="/img/icon/favicon.svg">
<link rel="apple-touch-icon" sizes="180x180" href="/img/icon/apple-touch-icon.png">
<link rel="mask-icon" color="#ffffff" href="/img/icon/favicon.svg">
```
`<link rel="manifest" href="pwa/manifest.json">`
- Web Manifestファイルを読み込むための記述
- href=はファイルを入れている場所。ルートファイルはpublicであり、それ以降を記述する。
- 今回の場合public/pwaのmanifest.jsonファイルということ

`<link rel="icon" type="image/png" sizes="16x16" href="/icon/favicon-16x16.png">`
- type="image/png"は形式、sizes="16x16"はサイズを表す。
- href=はファイルを入れている場所。ルートファイルはpublicであり、それ以降を記述する。
- 今回の場合public/iconのfavicon-16x16.pngファイルということ


### 画像をpublicではなくasset/imageファイルに入れたい場合
1.各サイズの画像をimageファイル入れる。
2.HTMLに書き込む
**例**
```
<%= favicon_link_tag 'favicon-16x16.png', rel: 'icon', type: 'image/png', sizes: '16x16' %>
<%= favicon_link_tag 'favicon-32x32.png', rel: 'icon', type: 'image/png', sizes: '32x32' %>
<%= favicon_link_tag 'apple-touch-icon.png', rel: 'apple-touch-icon', type: 'image/png' %>
```
- publicなら、`href="/icon/favicon-16x16.png`のところを`favicon_link_tag`に変更
