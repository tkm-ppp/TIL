# 経緯
テイルウインドが反応していない箇所があり使えるように調べているとローカルホストも立ち上がらなくなった。tailwindcssコマンドが見つからないことが原因と表示されている

# 目的
1　テイルウインドを動かせるようにする

2　ローカルホストが立ち上がるようにする

# 方針
tailwindcssコマンドを表示するようにする
### 表示されない原因
1.tailwindcssが正しくインストールされていない。

2.node_modules/.binがPATHに含まれていない。

# 方法（方針を具体化）
## 1. tailwindcssのインストール確認
```
ls node_modules/tailwindcss
```
### 結果：tailwindcssはインストールされている
```
root@pR:~/Projects/readlink# ls node_modules/tailwindcss
LICENSE    dist       package.json   theme.css
README.md  index.css  preflight.css  utilities.css
```

## 2.PATHの確認
node_modules/.binがPATHに含まれているか確認する。
```
echo $PATH
```
